Day 1: Start a day to learning and understanding the commands in git bash 

the commands: 
cd - change directory 
ls - list of all files 
pwd - print working directory 
git init - turn local folder into a git repository
ls -la -list all files including the hidden files 
mkdir - make directory 

git init - initialize a new git repository
git status - to track the files to see what changes, staged or untracked 
git add (file name) - to add a file and stages a specific file
git add . - stages everything in the folder
git commit -m "message" - saves your staged changes with a descriptive note 

git branch - list of all branches the * is where you are
git branch (name) - create a new branch with name 
git checkout (name) -(name) - switches your focus to that branch 
git checkout -b (name) - create a new branch and switch it into one step 
git merge (name) bring the changes from (name) into your current branch 
git branch -d - Deletes a branch (use this after you've merged it).

git remote add origin (url) - links my local folder to a github repository 
git push -u origin main - sends my local commits into github 
git pull - grabs the latest changes from a github and brings them to my pc 
git clone (url) downloads the entire github repository
